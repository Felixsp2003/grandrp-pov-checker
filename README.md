# Grand RP POV Checker V88

V88 erweitert den CSV-Bereich um zusätzliche Mehrfachfilter und deutlich mehr Sortiermöglichkeiten.

## CSV-Filter
- Bann-Typ/Status: Gebannt, Hardban, Soc-Ban, Cheater, PC-Check, Verweigerung, Trolling, Cleaning, Redux, Discord-Grund, Banevading, Acc 1.4, Event 1.7, Perma, Video/kein Video, Dokumentstatus, vollständig/offen, Proof und SC/Discord vorhanden/leer.
- Grund: exakter Grund.
- SC/SOC und Discord: vorhanden/leer.
- PC-Checker: dynamisch aus den gespeicherten Einträgen.
- Zeitraum: Von/Bis.
- Freitextsuche: ID, Proof, SC, Discord, Grund und Admins.

## CSV-Sortierung
Zusätzlich zu Datum, ID, Grund und SC gibt es Gruppensortierungen wie **Hardban zuerst/zuletzt**, Soc-Ban, Cheater, PC-Check, Verweigerungen, Trolling, Cleaning, Redux, Discord-Grund, Banevading, Perma, Vollständig, Dokument eingetragen, Proof, SC, Discord und fehlende Angaben.

Alle Filter wirken auf die Vorschau sowie auf **CSV kopieren**, **CSV herunterladen** und die Perma-CSV bleibt separat.

Der aktuelle Projektstand basiert auf dem bestehenden GrandRP POV Checker und behält Upload, YouTube, OCR, Archiv, manuelle Prüfung und OAuth bei.
