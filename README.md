Grand RP DC Checker V89

Website-Änderungen:
- 3 optionale YouTube-Verbindungen. Leere Felder werden ignoriert.
- Bei YouTube-Uploadlimit/Quota wird automatisch zur nächsten Verbindung gewechselt.
- Wenn alle Verbindungen blockiert sind, bleibt die POV dauerhaft in der Warteschlange und wird später automatisch erneut versucht.
- Warteschlange, Archiv-Metadaten und POV-Dateien werden dauerhaft über IndexedDB + localStorage gespeichert; persistenten Browser-Speicher wird angefordert.
- YouTube-Verbindungen werden ebenfalls redundant in localStorage + IndexedDB gespeichert.
- ACP V86 bleibt unverändert.

Hinweis: Browserdaten können vom Nutzer/Browser trotzdem vollständig gelöscht werden; dagegen kann eine reine Website keine absolute Garantie geben.
